# Internationalization (i18n) — Frontend Reference

> Extracted from: `front-end/ui-ux-i18n.md`

---

## Stack

| Library | Role |
|---------|------|
| `i18next` | Core i18n engine |
| `react-i18next` | React bindings (`useTranslation`, `Trans`) |
| `i18next-browser-languagedetector` | Auto-detect browser language |

---

## Configuration (`src/i18n.js`)

```javascript
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import LanguageDetector from 'i18next-browser-languagedetector'
import en from './i18n/locales/en.json'
import ar from './i18n/locales/ar.json'

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: { en: { translation: en }, ar: { translation: ar } },
    fallbackLng: 'en',
    lng: localStorage.getItem('atlas_lang') || 'en',
    interpolation: { escapeValue: false },
  })

export default i18n
```

## Global RTL / LTR Toggle

```javascript
// src/App.jsx — on mount and on language change
const applyLanguage = (lang) => {
  i18n.changeLanguage(lang)
  document.documentElement.dir  = lang === 'ar' ? 'rtl' : 'ltr'
  document.documentElement.lang = lang
  localStorage.setItem('atlas_lang', lang)
}
```

This is the ONLY place RTL is set. Never set `dir` per-component.

## Usage in Components

```jsx
import { useTranslation } from 'react-i18next'

const MyComponent = () => {
  const { t, i18n } = useTranslation()
  const isRTL = i18n.language === 'ar'

  return (
    <div>
      {/* ✅ All text through t() */}
      <h1>{t('farm.title')}</h1>
      <Button>{t('common.save', 'Save')}</Button>

      {/* ✅ RTL-aware layout */}
      <Box sx={{ textAlign: isRTL ? 'right' : 'left' }}>

      {/* ❌ WRONG — hardcoded text */}
      <h1>إدارة المزرعة</h1>
      <Button>Save</Button>
    </div>
  )
}
```

## Typography — Font by Language

```css
/* Loaded from Google Fonts in index.html */
@import url('https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700&family=Outfit:wght@400;500;600;700&display=swap');

/* Applied dynamically in App.jsx or global CSS */
:root[lang="ar"] { font-family: 'Cairo', sans-serif; }
:root[lang="en"] { font-family: 'Outfit', sans-serif; }
```

## Language Toggle Component

```jsx
const LanguageToggle = () => {
  const { i18n } = useTranslation()

  const toggle = () => {
    const next = i18n.language === 'ar' ? 'en' : 'ar'
    applyLanguage(next)  // from App.jsx utility
  }

  return (
    <Button onClick={toggle} variant="outlined" size="small">
      {i18n.language === 'ar' ? 'EN' : 'عربي'}
    </Button>
  )
}
```

## Rules

```
✅ All UI text through t('namespace.key', 'fallback')
✅ RTL set ONCE via document.documentElement.dir
✅ Font applied via :root[lang="ar/en"]
✅ Language persisted in localStorage as 'atlas_lang'

❌ Hardcoded Arabic strings in JSX
❌ Hardcoded English strings in JSX
❌ Per-component dir="rtl" attribute
❌ Per-component font-family override
❌ Two translation keys for the same concept
```
