# Atlas Farm ERP

A comprehensive, bilingual (RTL/LTR) Enterprise Resource Planning (ERP) platform for farm and agriculture management.

## Project Structure

- **Back-End/**: Contains the Django-based backend application, REST API endpoints, business logic, permissions, and service integrations.
- **Front-End/**: Contains the React/Vite-based frontend web application, Material-UI (MUI) components, routing, and modular views.
