## 🆘 TOP FIXES

### "Backend server is running" ❌
→ Run `start_server.bat` in Terminal 1

### "Admin user exists" ❌
→ Approve user:
```sql
UPDATE users_user SET is_approved = true WHERE email = 'admin@example.com';
```

### "Farm list respects tenant isolation" ❌ ⚠️
→ **SECURITY ISSUE** — Edit `services/farm_service.py` to add tenant filter

### "Reports returns 500" ❌
→ Check Django console for error, usually in serializers

### PostgreSQL error ❌
→ Start PostgreSQL: `net start postgresql-x64-16`

## 🌐 API ENDPOINTS (Manual Testing)

```bash
# Login
curl -X POST http://localhost:8000/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d "{\"email\": \"admin@example.com\", \"password\": \"admin\"}"

# Get current user
curl -X GET http://localhost:8000/api/auth/me/ \
  -H "Authorization: Bearer {TOKEN}"

# List farms
curl -X GET http://localhost:8000/api/farm/farms/ \
  -H "Authorization: Bearer {TOKEN}"

# List reports
curl -X GET http://localhost:8000/api/reports/tasks/ \
  -H "Authorization: Bearer {TOKEN}"
```
