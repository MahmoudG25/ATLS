- **Database**: Configure PostgreSQL with connection pooling
- **Authentication**: JWT backend configuration
- **Middleware**: Add tenant middleware, CORS middleware

- **Static/Media**: Configure for development and production
- **Logging**: Structured JSON logging

- **SECRET_KEY**: Environment-based security

**Step 2.2.4: Create Tenant System**

Files to create:
- `apps/backend/core/tenant.py` - TenantManager, custom QuerySet
- `apps/backend/models/base.py` - AbstractBaseModel with tenant_id
- `apps/backend/models/user.py` - User and Tenant models
- `apps/backend/core/middleware.py` - Request tenant injection middleware

Key implementation details:
- All models inherit from AbstractBaseModel with `tenant_id` field
- Custom manager filters all queries by current tenant
- Middleware extracts tenant from JWT token or HTTP header
- Tenant validation on every request

**Step 2.2.5: Create JWT Authentication**

Files to create:
- `apps/backend/api/endpoints/auth.py` - Login, Logout, Refresh endpoints
- `apps/backend/serializers/user_serializers.py` - User serialization

Endpoints:
- `POST /api/auth/login/` - Issue JWT tokens
- `POST /api/auth/refresh/` - Refresh access token
- `POST /api/auth/logout/` - Invalidate token (store in blacklist)

**Step 2.2.6: Create Audit Model**

Files to create:
- `apps/backend/models/audit.py` - AuditLog model for change tracking
- `apps/backend/services/audit_service.py` - Audit logging service

Fields:
- `tenant_id`, `user_id`, `model_name`, `action`, `changes`, `timestamp`
- Middleware hook to capture all create/update/delete operations

## 4. Risk Mitigation Summary

| Risk | Mitigation Strategy | Verification |
|------|---------------------|--------------|
| Tenant data leakage | Mandatory tenant_id filtering in all queries; middleware injection | Run isolation test; audit logs show only current tenant's data |
| JWT token exposure | Use SimpleJWT library; refresh token rotation; token blacklist on logout | Token refresh test passes; invalid token returns 401 |
| PostgreSQL connection issues | Configure pgBouncer; test connection pooling early | `psql` connects successfully from Django container |
| Offline sync conflicts | Establish sync queue architecture early; document conflict resolution | Service Worker registers; offline cache functional |
| CI/CD pipeline failures | Start minimal; expand incrementally; test locally first | Pipeline passes on clean branch |
